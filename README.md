# 裝備截圖工具（路塔尼亞 Lootania）

MapleStory Worlds「路塔尼亞 Lootania」用的裝備截圖小工具。
滑鼠停在遊戲裡的裝備上按快捷鍵，**只截下裝備說明框**，並用 Windows 內建的文字辨識讀出**裝備名稱自動命名**存檔。

## 功能

- 只截裝備說明框，不是整個畫面；說明框下半部疊在聊天框、道具圖示上也能完整截到
- 自動讀出裝備名稱、分類當檔名，例如 `戒指\鑽石戒指_20260928_184230.png`
- 截圖內容可選：一般畫面／Tab 詳細資訊／兩張並排成一張／兩張分開存
- 儲存前先預覽：可以改檔名、選資料夾，按 Enter 儲存、Esc 不要
- 依裝備分類自動分資料夾（帽子、戒指、弓弩…）
- 快捷鍵可自訂（預設 F8，可用組合鍵如 `ctrl+shift+s`）
- 預設存在 `桌面\裝備截圖`，可自己換資料夾

## 安裝

1. 安裝 [Python 3.10 以上](https://www.python.org/downloads/)
   安裝時記得勾選 **「Add python.exe to PATH」**。
2. 下載這個專案（綠色的 Code 按鈕 → Download ZIP），解壓縮。
3. 雙擊 **`安裝套件.bat`**（會用 pip 安裝 `requirements.txt` 裡的套件，只需要做一次）。
   也可以自己在命令提示字元執行：
   ```bash
   pip install -r requirements.txt
   ```
4. 雙擊 **`裝備截圖.pyw`** 開啟。

## 使用方法

1. 開啟 `裝備截圖.pyw`（可以縮到工作列）。
2. 在遊戲裡把滑鼠停在裝備上，等說明框出現，按快捷鍵（預設 **F8**）。
3. 跳出預覽視窗 → 確認檔名 → 按 **Enter** 儲存（**Esc** 不要）。

## 這個程式會做什麼（安全性說明）

程式碼全部公開，可以自己檢查。它**只會**做這些事：

| 動作 | 為什麼 |
|---|---|
| 監聽你設定的快捷鍵 | 按下快捷鍵時才開始截圖（使用 `keyboard` 套件） |
| 擷取滑鼠附近的螢幕畫面 | 找出裝備說明框（使用 `mss` 套件） |
| 模擬按一下 **Tab** 鍵 | 截「Tab 詳細資訊」畫面時用；選「一般畫面」就不會按 |
| 滑鼠瞬間移到螢幕左上角再移回來 | 拍一張沒有說明框的背景，用來找出完整的說明框範圍 |
| 用 Windows 內建的文字辨識讀字 | 讀裝備名稱當檔名，在你的電腦上處理 |
| 在你指定的資料夾存 PNG 圖片 | 截圖本身 |

它**不會**連網路、不會上傳任何東西、不會讀寫遊戲的檔案或記憶體、不會點擊遊戲裡的任何東西。

## 設定

| 設定 | 說明 |
|---|---|
| 儲存位置 | 預設 `桌面\裝備截圖`，按「選擇…」可以換 |
| 快捷鍵 | 直接輸入（例：`f8`、`ctrl+shift+s`、`alt+q`）按「套用」，或按「錄製…」再按鍵盤 |
| 截圖內容 | 一般畫面／Tab 詳細資訊／兩張並排／兩張分開存 |
| 檔名格式 | 可用 `{名稱}` `{分類}` `{等級}` `{日期}` `{時間}`，預設 `{名稱}_{日期}_{時間}` |
| 依分類放進子資料夾 | 例：`裝備截圖\戒指\紅寶石戒指_….png` |
| 儲存前先預覽 | 取消勾選就是按快捷鍵直接存 |

設定會存在程式旁邊的 `screenshot_settings.json`。

## 常見問題

- **在遊戲裡按快捷鍵沒反應**
  遊戲如果是用「系統管理員」身分執行，這個程式也要用系統管理員身分執行
  （在命令提示字元用系統管理員開啟後執行 `pythonw 裝備截圖.pyw`）。
- **檔名都是「裝備_日期_時間」，讀不到裝備名稱**
  需要 Windows 有「中文（台灣）」語言（設定 → 時間與語言 → 語言與地區 → 新增「中文（台灣）」）。
  沒有也沒關係，截圖照樣會存，只是要自己改檔名。
- **想給沒有 Python 的朋友用**
  雙擊 `打包成exe.bat`，會用 PyInstaller 打包出 `dist\裝備截圖.exe`。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `裝備截圖.pyw` | 主程式（視窗、快捷鍵、截圖、存檔、預覽） |
| `item_capture.py` | 找裝備說明框、扣掉半透明背景、文字辨識 |
| `equipment.py`、`character_sheet.py` | 裝備部位、屬性名稱（修正文字辨識讀錯的字） |
| `requirements.txt` | 需要安裝的 Python 套件 |
| `安裝套件.bat` | 一鍵安裝套件 |
| `打包成exe.bat` | 自己打包成 exe |
